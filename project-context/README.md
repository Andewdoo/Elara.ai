# Elara Project Context

This folder is the authoritative home for planning, task prompts, operating guidance, and release evidence used by Codex tasks.

- [AGENTS.md](AGENTS.md): project rules and completion criteria.
- [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md): architecture and implementation steps.
- [prompts](prompts): full-mode numbered task prompts.
- [LITE_MODE_PLAN.md](LITE_MODE_PLAN.md) and [lite-prompts](lite-prompts): Lite Mode plan and prompts.
- [operations](operations/): private AWS deployment guidance, future public-production guidance, Step 25 operations, validation evidence, Lite deployment guidance, and Step 24B governance controls.

Application-specific READMEs remain beside their code, and the repository root `AGENTS.md` remains in place because tooling uses it as the top-level instruction file.
